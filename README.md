## 1. 环境搭建

### 1.1 硬件要求

| 项目 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 4 核 | 8 核以上 |
| 内存 | 8 GB | 16 GB 以上 |
| GPU | 可选（非必须） | NVIDIA GTX 1060 以上 |
| 硬盘 | 10 GB 空闲 | SSD 50 GB 以上 |

> **FeatureBank 模式无需 GPU**，CPU 即可快速完成特征库构建。

### 1.2 软件环境

```bash
# 1) 确认 Python 版本（要求 3.8 ~ 3.10）
python --version

# 2) 进入项目目录
cd E:\Code\study\SuperSimpleNet-Defect-Detection

# 3) 安装依赖
pip install -r requirements.txt
```

`requirements.txt` 核心依赖：

| 包名 | 用途 |
|------|------|
| torch>=2.0.0 | 深度学习框架 |
| torchvision>=0.15.0 | 图像处理与预训练模型 |
| PyQt5>=5.15.0 | GUI 界面 |
| opencv-python>=4.8.0 | 图像处理 |
| numpy>=1.24.0 | 数值计算 |

> **GPU 用户**：请根据 CUDA 版本安装对应 PyTorch，参考：
> - CUDA 11.8：`pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118`
> - CUDA 12.1：`pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121`

### 1.3 启动系统

```bash
python main.py
```

启动后界面布局：
- **左侧**：训练面板（选择数据 → 选择骨干网络 → 一键训练）
- **右侧**：推理面板（选择待检图像 → 批量/单张推理 → 结果展示）
- **顶部**：菜单栏（文件 / 模型 / 视图 / 帮助）

## 2. 数据准备

### 2.1 数据组织规范

请按以下目录结构组织数据：

```
datas/
├── ok/          # OK（正常）样本，仅用于训练
│   ├── 001.jpg
│   ├── 002.png
│   └── ...
└── ng/          # NG（缺陷）样本，仅用于评估（可选）
    ├── 101.jpg
    └── ...
```

### 2.2 数据要求

| 项目 | 要求 |
|------|------|
| 图像格式 | .jpg / .jpeg / .png / .bmp / .tiff |
| 样本数量 | OK 样本 **建议 ≥ 30 张**，越多效果越好 |
| 图像内容 | 仅包含 **正常无缺陷** 的产品图像 |
| 图像尺寸 | 自动缩放到 224×224，无需预先裁剪 |
| 光照条件 | 尽量与推理环境一致 |

### 2.3 操作步骤

```
菜单栏 → 文件 → 打开训练数据文件夹
或
训练面板 → ① 选择OK样本文件夹 → 点击「选择文件夹」
```

> 选择成功后，面板会显示：`已加载 N 个OK样本`

## 3. 训练操作

### 3.1 流程概览

```
选择OK样本 → 选择骨干网络 → 一键训练 → 自动保存模型 → 自动加载推理
```

### 3.2 分步操作

#### Step 1：选择 OK 样本文件夹

- 点击训练面板的 **「选择文件夹」** 按钮
- 选择包含 OK 样本的文件夹（如 `datas/ok/`）
- 确认路径显示和样本数量正确

#### Step 2：选择骨干网络

| 骨干网络 | 速度 | 效果 | 推荐场景 |
|----------|------|------|----------|
| resnet18 | ⚡ 最快 | ⭐⭐⭐ | 快速验证、实时检测 |
| **resnet50** | ⚡⚡ 适中 | ⭐⭐⭐⭐ | **默认推荐，平衡效果与速度** |
| wide_resnet50_2 | ⚡⚡⚡ 较慢 | ⭐⭐⭐⭐⭐ | 高精度要求场景 |

> 在下拉框中选择即可，**无需修改其他参数**。

#### Step 3：一键训练

点击 **「开始训练」** 按钮，系统自动执行：

```
① 扫描文件夹 → ② 加载预训练ResNet骨干网络（冻结）
③ 提取所有OK样本的特征 → ④ 构建特征库
⑤ 分析OK得分分布 → ⑥ 自动计算判定阈值
⑦ 保存模型 → ⑧ 自动加载推理引擎
```

**训练状态说明**：

| 状态栏显示 | 含义 |
|------------|------|
| 正在提取特征...请稍候 | 正在提取第 N/M 张图像的特征 |
| 特征库构建完成 | 成功完成，耗时 X 秒 |
| 训练完成！ | 模型已保存并加载，可进行推理 |

### 3.3 训练完成后

- 模型自动保存到 `checkpoints/model_deploy.pth`
- 推理引擎自动加载该模型
- 状态栏显示模型摘要信息，包括：
  - OK 样本数、特征维度
  - OK 得分均值/标准差
  - 建议阈值
  - 构建耗时

## 4. 推理检测

### 4.1 流程概览

```
选择待检文件夹 → 批量推理 → 查看结果（OK/NG、得分、耗时）
```

### 4.2 分步操作

#### Step 1：选择待检测图像文件夹

```
菜单栏 → 文件 → 打开推理数据文件夹
或
推理面板 → 点击「选择文件夹」
```

支持选择包含子文件夹的目录，系统会自动递归扫描所有图像。

#### Step 2：执行批量推理

点击 **「开始批量推理」**，系统逐张检测并展示结果。

#### Step 3：查看结果

每张图像的检测结果包含：

| 字段 | 说明 |
|------|------|
| OK/NG 标签 | ✅ OK = 正常，⚠ NG = 异常（缺陷） |
| 异常得分 | 0~1 之间，**越高越异常** |
| 推理耗时 | 每张图像的处理时间（毫秒） |
| 判定阈值 | 当前使用的判定分界线 |

**结果覆盖层颜色说明**：

| 颜色 | 含义 |
|------|------|
| 🟢 绿色边框 | OK — 正常通过 |
| 🔴 红色边框 | NG — 检出异常 |

#### Step 4：单张检测（可选）

在图像列表中点击任意图像，可：
- 放大预览原图
- 查看单张详细判定信息
- 观察异常得分数值

### 4.3 结果解读

```
异常得分范围 [0, 1]：
  score < 阈值  → OK（正常）— 与正常样本特征分布一致
  score ≥ 阈值  → NG（异常）— 偏离正常分布，可能存在缺陷

阈值说明：
  - 训练时自动根据 OK 样本得分分布计算（均值 + 3σ）
  - 可在配置中手动调整（通常无需修改）
```

## 5. 模型管理

### 5.1 浏览已保存的模型

```
菜单栏 → 模型 → 浏览已保存的模型
```

打开模型管理对话框，展示所有历史模型的：

| 列 | 说明 |
|----|------|
| 模型名称 | 训练时设定的名称 |
| 类型 | 神经网络 / 特征库 |
| 骨干网络 | 使用的特征提取网络 |
| 样本数 / Loss | 特征库模式显示样本数，神经网络模式显示最佳Loss |
| 创建时间 | 模型训练完成时间 |

### 5.2 加载历史模型

两种方式：
1. **模型管理对话框**：选中模型 → 点击「加载选中模型」
2. **菜单栏**：模型 → 加载模型文件 → 选择 `.pth` 文件

> 系统会自动校验模型完整性、版本兼容性，并展示模型摘要信息。

### 5.3 导出部署模型

```
菜单栏 → 模型 → 导出部署模型
```

导出的模型文件 (`model_deploy.pth`) 包含：
- 特征库或网络权重
- 训练配置参数
- 参考嵌入（正常样本特征中心）
- 系统版本号

## 6. 常见问题排查

### 6.1 训练问题

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| 选择文件夹后显示 0 个样本 | 文件夹为空或格式不支持 | 检查图像格式（支持 jpg/png/bmp/tiff） |
| 训练按钮灰色不可点击 | 未选择数据文件夹 | 先选择 OK 样本文件夹 |
| 特征库构建失败 | 样本数量太少或图像损坏 | 确保 ≥ 10 张有效 OK 样本 |
| 训练时卡住 | 数据集读取异常 | 检查图像文件是否完整无损 |

### 6.2 推理问题

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| 所有图像都判为 OK | 阈值太高 | 重新训练或手动调低阈值 |
| 所有图像都判为 NG | 阈值太低 | 重新训练或手动调高阈值 |
| NG 漏检率高 | 模型不够敏感 | 换用更大骨干网络（如 wide_resnet50_2） |
| OK 误检率高 | OK 样本多样性不足 | 增加更多不同类型的 OK 样本 |
| 推理速度慢 | 骨干网络过大 | 换用 resnet18 提升速度 |

### 6.3 环境问题

| 问题 | 解决方法 |
|------|----------|
| `ModuleNotFoundError: No module named 'torch'` | 执行 `pip install torch torchvision` |
| `No module named 'PyQt5'` | 执行 `pip install PyQt5` |
| `OpenCV Error: ...` | 执行 `pip install opencv-python` |
| GPU 内存不足 | 系统自动 fallback 到 CPU，或减少 batch_size |
| 中文乱码 | 确保系统安装中文字体（如微软雅黑） |

### 6.4 日志查看

所有操作记录在 `logs/` 目录下：

```
logs/
├── 2026-06-10.log         # 主日志（所有级别）
├── error_2026-06-10.log   # 错误日志（仅 ERROR 级别）
└── operation_history.json # 操作历史记录
```

查看最新日志：

```bash
# 查看今天的所有日志
type logs\2026-06-10.log

# 查看错误信息
type logs\error_2026-06-10.log
```

## 附录

### A. 一键运行流程（命令行版）

```bash
# 如果有独立的 OK/NG 测试数据，可使用命令行流水线
python -c "
from core.feature_bank import run_feature_bank_pipeline

run_feature_bank_pipeline(
    ok_dir=r'E:\Code\study\datas\ok',      # OK 训练样本目录
    ng_dir=r'E:\Code\study\datas\ng',      # NG 评估样本目录（可选）
    infer_dir=r'E:\Code\study\datas',      # 推理目录
    backbone='resnet50',                   # 骨干网络
    n_neighbors=3,                         # kNN 邻居数
)
"
```

### B. 关键默认参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| backbone | resnet50 | 特征提取骨干网络 |
| image_size | [224, 224] | 输入图像尺寸 |
| batch_size | 16 | 批处理大小 |
| embedding_dim | 128 | 嵌入向量维度 |
| threshold | 自动计算 | 异常判定阈值（均值 + 3σ） |
